# Воспроизводимость

Для воспроизведения эксперимента необходимо:

1. Развернуть Zabbix Server и Zabbix Frontend.
2. Обеспечить доступность SNMP v2c на исследуемых устройствах.
3. Выполнить сбор SNMP-дампов с помощью `scripts/collect_snmp.sh`.
4. Импортировать шаблоны из каталога `zabbix_templates/`.
5. Привязать raw- и semantic-шаблоны к соответствующим хостам.
6. Проверить появление метрик:
   - `system.cpu.util`
   - `system.memory.util`
7. Построить общий график по одной из semantic-метрик.

## Ограничения

- Индексы CPU/RAM могут отличаться на других устройствах.
- Для vESR полный обход `1.3.6.1.4.1` может приводить к timeout.
- Значения memory метрик могут отличаться по семантике free/available/cached.
